# Robô 3 - Compara Ofertas

Este repositório contém o sistema autônomo do **Robô 3 (Compara Ofertas)**, parte do Projeto Mestre Compara Preço.

## 🎯 Objetivo
O Robô 3 é especializado em monitorar e divulgar as melhores ofertas do Mercado Livre nas categorias:
- Casa
- Games
- TV e Vídeo
- Celular
- Moda

## 🚀 Funcionalidades
- **Busca Automática**: Scripts Python que consultam a API do Mercado Livre.
- **Geração Estática**: Criação automática de páginas HTML otimizadas para SEO.
- **Melhorias AdSense**: Implementação automática de Schema Markup, Open Graph e Tags Alt.
- **SEO Otimizado**: Estrutura de categorias e links internos para melhor ranqueamento.

## 🛠️ Estrutura do Projeto
- `scripts/`: Scripts de automação (fetch, generate, apply enhancements).
- `data/`: Arquivos de configuração e dados de produtos.
- `categorias/`: Páginas de categorias geradas.
- `assets/`: Imagens, CSS e JS.

## 📈 Como Funciona
O sistema foi projetado para rodar de forma automática, atualizando os produtos e as páginas periodicamente para garantir que as ofertas estejam sempre atualizadas.
